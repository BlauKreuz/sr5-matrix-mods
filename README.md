# sr5-matrix-mods

Custom gameplay elements for Matrix icons and Hosts

For help and suggestions: [![Discord Server](https://img.shields.io/badge/-Discord-%232c2f33?style=flat-square&logo=discord)](https://discord.gg/NyCX2nN4qP)

- Players see only the persona or device icons from same network where they are connected. If they are not connected, icons list is empty.
- Icon list does not show the persona if the device is only connected to network but not equipped. Instead it shows the device itself and other items connected to it or online in that actor's inventory.
- GM sees all icons, but icons from other networks are dimmed.

- An experimental Host actor can be created by creating an IC actor and right-clicking it in right side menu -> "SR5 Matrix Mods: Toggle Host Variant". After that it can be connected to a network through its network manager (-> connect to to network). Thus, it appears in actors' Icons tab and can be used as target to "Brute Force" and "Hack On The Fly". This could be used when playing Matrix as a scene.
- Online character sees all hosts in icons list, but hosts from other networks are dimmed.
- Hosts show their items/devices only in the Marked tab, not in Icons tab.
